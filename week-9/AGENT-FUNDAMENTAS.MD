# Agent Fundamentals

## What is an AI Agent?
An AI agent is a system that performs:
Perception → Reasoning → Action

## Agent vs Chatbot
- Chatbot: single-step response
- Agent: multi-step decision system

## ReAct Pattern
Agents follow:
Thought → Action → Observation

## Message-Based Communication
Agents communicate via structured messages instead of direct calls.

## Role Isolation
Each agent performs a specific task:
- Research Agent → gathers info
- Summarizer Agent → compresses info
- Answer Agent → produces final output

## Memory
Each agent maintains a rolling memory window of 10 messages.
